# معلّم بلس | Moallem Plus

مساحة عمل عربية كاملة على جهاز المعلم لإعداد **خطط الدروس** و**الأنشطة الصفية** و**الاختبارات** و**بطاقات التفكير** — بلا حسابات، بلا خادم، وبلا اتصال بالإنترنت.

> كل شيء يعمل محليًا في متصفحك: بياناتك تُحفظ في `localStorage` على جهازك، وتُصدَّر/تُستورد ملفًا JSON لتأمينها أو نقلها بين الأجهزة.

**رابط الموقع المنشور:** https://hnyth50-gif.github.io/moallem-plus/

---

## الفكرة

المعلم يقضي وقتًا طويلًا في تجهيز الورق: خطة الدرس، نشاط مصمّم باتجاهٍ واضح، ورقة اختبار غير متطابقة مع نسخة الصف المجاور، واستراتيجية تفكير مناسبة للحصة. «معلّم بلس» يجمعها في مكان واحد سريع، عربي RTL بالكامل، وبإمكانية طباعة نظيفة جاهزة للتوزيع.

## المميزات

- **خطط الدروس**: أهداف وموارد بضغطة إضافة، مراحل زمنية تُوزَّع تلقائيًا حسب مدة الحصة (مجموع الدقائق مساوٍ تمامًا للمدة)، واجب وملاحظات، ومعاينة سريعة أثناء الكتابة.
- **الأنشطة الصفية**: خطوات مؤقّتة، مواد وأدوات، وربط النشاط ببطاقة استراتيجية من المكتبة.
- **الاختبارات**: بنك أسئلة بأنواع أربعة (اختيار من متعدد، صح/خطأ، إجابة قصيرة، مقالي)، هياكل جاهزة، **خلط حتمي** بترتيب مختلف لكل طباعة، **موازنة الصعوبة** (40% سهل / 40% متوسط / 20% صعب)، و**نسختان (أ/ب)** بخيارات مخلوطة مع مفاتيح إجابة مطابقة للنسخة.
- **بطاقات التفكير**: مكتبة جاهزة من 27 استراتيجية بستِّ تصنيفات، مع إمكانية إضافة بطاقات خاصة، و«بطاقة اليوم» الدالة على التاريخ.
- **طباعة نظيفة**: صفحات ورقية A4 منسقة (ترويسة مدرسة/معلم/فصل، أسطر إجابة، توقيعات، فصل صفحات بين النسختين).
- **وضع فاتح/داكن/حسب النظام** مع حفظ التفضيل، ودعم إتاحة الوصول (تنقل بلوحة المفاتيح، aria، تخطٍ إلى المحتوى).
- **بيانات تجريبية واضحة**: عناصر موسومة بشارة «تجريبي» تُضاف وتُزال بضغطة واحدة من الإعدادات — لا تختلط أبدًا ببياناتك.
- **تصدير/استيراد JSON**: نسخة احتياطية كاملة، واستيراد بوضع «دمج» (الأحدث يفوز) أو «استبدال»، مع تحقق صارم يهمل الملفات التالفة بأمان.
- **تطبيق قابل للتثبيت (PWA)**: ثبّته على شاشة هاتفك، ويعمل دون اتصال بعد أول زيارة (انظر القسم التالي).

## التثبيت كتطبيق على الهاتف (PWA)

الموقع تطبيق ويب تقدمي كامل:

- **ملف التعريف** `public/manifest.webmanifest`: الاسم والاسم المختصر، رابط البدء `./`، وضع العرض المستقل `standalone`، لونا السمة والخلفية، الاتجاه `rtl` واللغة `ar`.
- **الأيقونات** في `public/icons/`: 192 و512 بأي مقاس، وأيقونة **maskable** لأندرويد (الرمز داخل المنطقة الآمنة المركزية)، وأيقونة **180×180 لأيفون** عبر `apple-touch-icon`.
- **العمل دون اتصال** عبر `vite-plugin-pwa` (Workbox):
  - **الشبكة أولًا (NetworkFirst)** للصفحات والتنقل، بمهلة 3 ثوانٍ قبل الرجوع للكاش.
  - **التخزين أولًا (CacheFirst)** للأصول ذات الأسماء المتغيرة (hashed) تحت `assets/`.
  - تخزين مسبق (precache) لملفات التطبيق: HTML وCSS وJS والأيقونات.
- **تسجيل حِطيّ**: لا يُسجَّل عامل الخدمة في بيئة التطوير ولا داخل إطارات المعاينة (iframe)، وتُستثنى مسارات تسجيل الدخول وروابط OAuth (الأنماط: `login`، `oauth`، `signin`، `signup`، `auth`، `callback`) من مصادفة التنقل.

**طريقة التثبيت:**
- أندرويد (Chrome): قائمة ⋮ ← «إضافة إلى الشاشة الرئيسية».
- آيفون (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## التقنيات

| الطبقة | الاختيار |
|---|---|
| الواجهة | React 18 + TypeScript (strict) |
| المسارات | react-router-dom 6 مع `HashRouter` (يناسب الاستضافة الثابتة) |
| الأنماط | Tailwind CSS 3.4 (توافق RTL أصيل عبر `start/end`) |
| البناء | Vite 5 (رمز أساس `base: './'` ليعمل تحت أي مسار) |
| PWA | vite-plugin-pwa (Workbox 7) — عمل دون اتصال + تثبيت |
| الاختبارات | Vitest 2 + Testing Library (jsdom) — 147 اختبارًا |
| الأيقونات | SVG داخلية بلا مكتبات خارجية |
| التخزين | `localStorage` فقط — لا خادم، لا مفاتيح API، لا تتبّع |

## التشغيل محليًا

```bash
# المتطلبات: Node.js 20 أو أحدث
npm install
npm run dev          # خادم التطوير على الميناء 5174
```

## البناء والمعاينة

```bash
npm run build        # تحقق TypeScript ثم بناء الإنتاج إلى dist/
npm run preview      # معاينة البناء على الميناء 4173
```

## الاختبارات

```bash
npm test             # تشغيل واحد لكل ملفات الاختبارات
npm run test:watch   # وضع المراقبة أثناء التطوير
```

تغطي الاختبارات: محرك الاختبارات (خلط حتمي وموازنة صعوبة بلا تكرار)، محرك الخطة (توزيع دقائق مساوٍ للمدة)، طبقة التخزين، عمليات المتجر والدمج، التحقق من الاستيراد (هدم الملفات المشوهة بأمان)، مكتبة الاستراتيجيات، البيانات التجريبية، وتفاعلات الواجهة الأساسية (RTL، الوضع الداكن، تكامل localStorage).

## الاستضافة والنشر

النشر آلي تمامًا عبر GitHub Actions (ملف `.github/workflows/pages.yml`):

1. سير العمل يشتغل عند كل دفعة (push) إلى الفرع `main`.
2. يشغّل `npm ci` ثم `npm test` (كل الاختبارات) ثم `npm run build`.
3. يرفع مجلد `dist/` وينشره إلى GitHub Pages.

الخطوات المفصلة (إنشاء المستودع وتفعيل Pages) موثقة في [DEPLOY.md](DEPLOY.md).

## لقطات الحالة (Snapshots) — الرجوع لأي لحظة

كل مرة تجري فيها تغييرًا احفظ «لقطة» لنقعه عن التعديلات غير المرغوبة. مرة واحدة فقط (غالبًا) ثم في كل تعديل:

```cmd
snapshot "وصف التغيير هنا"        ← يثبّت التغيير + شارة بتاريخه (ثم دفع إلى GitHub تلقائيًا)
snapshot -List                    ← عرض كل اللقطات مع تواريخها
```

ماذا يحدث فعليًا: تُثبَّت كل الملفات في commit يضم تعليقك **والتاريخ والوقت**، وتُأخذ شارة Git موسومة باسم `snap-<تاريخ-وقت>`، ثم تُرفَع إلى GitHub حتى تبقى اللقطات ناجية من أي فساد في المجلد.

**للعودة إلى لقطة سابقة:**

```bash
git checkout main
git reset --hard snap-20261023-120000   # اسم اللقطة من snapshot -List
```

> تحذير: `reset --hard` يزيل كل ما جاء *بعد* اللقطة محليًا. للاستعراض فقط دون تعديل استخدم: `git checkout snap-<اسم-اللقطة>` ثم `git checkout main` للعودة.

## بنية المشروع

```
.github/workflows/pages.yml   سير النشر الآلي (build → test → deploy)
public/                       الشعار (favicon.svg)
src/
  lib/          منطق خالص قابل للاختبار: محركا الاختبار والخطة، التخزين،
                 التحقق من البيانات، مكتبة الاستراتيجيات، البيانات التجريبية
  state/        سياقات React: البيانات (CRUD كامل)، المظهر، التنبيهات
  components/   مكتبة واجهة (أزرار/حقول/حواريات)، التخطيط، الطباعة، الأيقونات
  pages/        الشاشات: اللوحة الرئيسية، المحررات الثلاثة، البطاقات، الإعدادات
tests/          اختبارات Vitest (+ setup لبيئة jsdom)
```

## الخصوصية

- لا يوجد خادم ولا حسابات ولا تتبّع ولا إعلانات: **صفر** طلبات شبكة بعد تحميل الملفات الثابتة.
- بياناتك على جهازك: الحفظ في `localStorage`، والنقل عبر ملف JSON تديره أنت.
- «حذف كل البيانات» من الإعدادات يمسح كل شيء محليًا بطلب تأكيد كتابي.
